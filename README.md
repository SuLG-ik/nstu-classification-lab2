## Запуск

Нужен Python 3.13. Команды для macOS и Linux выполняются из папки репозитория:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook lab2.ipynb
```

Выбрать ядро созданного окружения и выполнить ячейки по порядку. Полная сетка нейросетей обучается на CPU; время зависит от компьютера. Графики и таблицы сохраняются в ноутбуке, служебные файлы находятся в `runtime/` и не входят в Git.

Для просмотра обучения после запуска ноутбука:

```bash
tensorboard --logdir runtime/logs --host 127.0.0.1 --port 6006
```

Открыть `http://127.0.0.1:6006`, выбрать два эксперимента и сравнить loss и accuracy на train и validation.
